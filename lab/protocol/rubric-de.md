# Bewertungsleitfaden (Phase 0)

Grundlage: Spec §15.2–15.3. Jedes Kriterium ist bestanden oder nicht. Im Zweifel: nicht bestanden, Notiz schreiben.

| Kriterium | Bestanden, wenn … |
| --- | --- |
| Bezug zur Aufgabe | der Kandidat die gewünschte kleine Änderung versucht, nichts Themenfremdes |
| Lesbar | man erkennt, was gezeichnet werden soll |
| Passgenau | der Kandidat ohne Raten auf dem Foto liegt |
| Richtige Stelle | die neuen Striche dort liegen, wo die Änderung hin soll |
| Entspricht der Änderung | Umfang und Art zur vorab festgelegten Änderung passen |
| Keine Konturzerstörung | keine markierte kritische Kontur entfernt, gebrochen, verändert oder verdeckt wird, sodass man sie nachzeichnen oder retten müsste |
| Saubere Ebene | die Ebene keine Papiertextur, keinen Farbstich, keinen Schatten und keine großen deckenden Flächen enthält |
| Fineliner-plausibel | es mit schwarzem Fineliner so aussehen kann (kein Weiß, keine Farbe, keine Lavierung) |
| Ausführbar | eine Anfängerin oder ein Anfänger es physisch zeichnen kann |
| Allein verständlich | man auf weißem Hintergrund allein sagen kann, was und wo zu zeichnen ist |

**controlled** = S2 oder S3, Grenzprüfung bestanden, alle Kriterien bestanden.
**experimental** = S1 nach Rückkopie, oder S2/S3 mit mindestens einem nicht bestandenen Kriterium, aber zur Aufgabe passend und lesbar.
**rejected** = themenfremd, unlesbar, nicht passgenau.

Die Klassifikation berechnet das Werkzeug aus den Häkchen; nicht selbst eintragen.
