# Phase 0 Prompt Templates

**Revision:** `ideas-s3-v1`, `s1-v1`, `s2-v1` (frozen 2026-10-03). Any change gets a new revision and is recorded in the attempt log; never edit a template mid-run.

Placeholders in `{braces}` are filled from the case manifest. `{material_sheet}` is the output of `uv run nextstroke-lab material-sheet protocol/material-sheet.json`; `{stroke_plan_schema}` is `protocol/stroke-plan.schema.json`. The model-facing text is German because the `v0.1` product is German (D-040).

## Claude Project instructions: ideas and S3 strokes (`ideas-s3-v1`)

Set once as the Claude Project's instructions. Each case is one new chat with the case photo attached.

```text
Du hilfst einer Anfängerin oder einem Anfänger, eine begonnene Fineliner-Zeichnung weiterzuführen.

Regeln:
- Werkzeug: nur der angegebene schwarze Fineliner auf dem angegebenen Papier. Kein Weiß, keine Farbe, kein Radieren, kein Wasser.
- Verwende ausschließlich die Materialfakten aus dem Materialblatt unten und nenne ihre IDs. Erfinde keine Eigenschaften von Stift oder Papier. Wenn ein Fakt fehlt, sei vorsichtig und sag es.
- Bestehende Linien bleiben unverändert. Der Bereich „nicht verändern“ ist tabu.
- Kleine, umkehrbare Schritte; zuerst ein Probestrich auf einem Reststück Papier.

Antworte in zwei Teilen.

Teil 1 – genau drei Ideen als JSON:
{"ideas": [{"title": "...", "risk": "Careful|Balanced|Bold", "technique": "...",
  "steps": ["...", "..."], "material_fact_ids": ["..."], "why": "..."}]}

Teil 2 – nur wenn ich danach „Striche für: <Änderung>“ schreibe: ein Strichplan als JSON nach diesem Schema,
ohne weiteren Text. Koordinaten 0..1 relativ zum Foto (0,0 = oben links), width als Anteil der längsten Bildkante
(Fineliner 0.1–0.5 mm entsprechen meist 0.0005–0.003), darkness 0..1, order = Zeichenreihenfolge.
{stroke_plan_schema}

Materialblatt:
{material_sheet}
```

Per case, first message: `Fall {case_id}. Stift: {pen}. Papier: {paper}. Ziel: {intent}. Nicht verändern: {protected_description}.` with the photo.

Second message in the same chat: `Striche für: {desired_change}` (the pre-registered change from the manifest, not the model's own idea).

Save part 1 as `{case_id}-ideas.json` and part 2 as `{case_id}-s3-{attempt}.json`. For attempts 2 and 3, start a new chat (no memory of the failed attempt) unless the attempt log notes otherwise.

## ChatGPT S1 masked edit (`s1-v1`)

Upload the case's 3:2 working photo, select the editable region with the edit brush, then:

```text
Ergänze nur im markierten Bereich: {desired_change}. Schwarzer Fineliner, gleiche Strichstärke und gleicher Stil
wie die vorhandenen Linien. Alles andere bleibt exakt unverändert. Keine neuen Farben, kein Weiß, kein Schatten.
```

## ChatGPT S2 transparent overlay (`s2-v1`)

Upload the case's 3:2 working photo as reference, then:

```text
Erzeuge ein PNG mit transparentem Hintergrund im Seitenverhältnis dieses Fotos ({orientation}, 3:2).
Es enthält NUR die neuen Striche für: {desired_change}, an genau der Stelle, an der sie auf diesem Foto
gezeichnet würden. Schwarze Fineliner-Linien. Kein Papier, keine vorhandenen Linien, kein Schatten,
kein Hintergrund, keine Farbe.
```

API route (D-046): `nextstroke-lab openai-run` sends the same S1/S2 text via `/v1/images/edits`. S1 uses the editable region as the mask in place of the edit brush; S2 attaches the photo as reference.

## v2 revisions for the follow-up test (`s1-v2`, `s2-v2`, `s3-v2`, D-049, frozen 2026-10-03)

Built from OpenAI's GPT Image 2.5 prompting guide (`developers.openai.com/api/docs/guides/image-prompting`, checked 2026-10-03). The OpenAI prompts are generated by `case_prompts.s1_prompt_v2` / `s2_prompt_v2`; placeholders are the annotation's `desired_change_en` and `protected_description_en`. Image 2 is the working photo with the editable region outlined in magenta. Settings: `gpt-image-2.5-sunburst`, `quality=high`, S2 `background=transparent`, S1 `background=opaque` with the editable mask on Image 1.

S2 (`s2-v2`):

```text
Image 1: a photo of a black fineliner drawing on paper ({{landscape 3:2 | portrait 2:3}}). It is the position reference.
Image 2: the same photo with the allowed drawing area outlined in magenta.

Task: create a transparent overlay that contains only new pen strokes. The overlay will be laid exactly on top of Image 1 at the same size and alignment, so every new stroke must be at the exact position where it would be drawn on Image 1.

New strokes: {{change}}.
Placement: only inside the magenta outline of Image 2, aligned to the existing lines and shapes of Image 1.
Style: black fineliner ink, thin uniform hand-drawn lines like the existing ones, pure black, no grey tones.
Keep unchanged: {{protect}}. Existing lines are not part of the overlay.

Output: only the new strokes on a fully transparent background.
Do not include: the photo, paper, existing lines, the magenta outline, a checkerboard, a backdrop, shadows, grey tones, colour, solid fills, text or a frame.
```

S1 (`s1-v2`):

```text
Image 1: a photo of a black fineliner drawing on paper. Edit this image.
Image 2: the same photo with the editable area outlined in magenta (reference only).

Change only: {{change}}, drawn inside the masked area (the magenta outline in Image 2).
Style: black fineliner ink, thin uniform hand-drawn lines like the existing ones, pure black, no grey tones.
Keep exactly the same: every existing line (position, shape, thickness), {{protect}}, the paper colour and texture, lighting, perspective, framing, crop and image size. Everything outside the masked area stays unchanged.
Do not add: colour, white ink, grey wash or tonal shading, shadows, text, signatures, the magenta outline or any other object.
```

S3 (`s3-v2`), one contextless subagent per case with Bild 1 (photo) and Bild 2 (outlined photo), then the message `Fall {case_id}. Striche für: {desired_change}. Nicht verändern: {protected_description}.`:

```text
Du erstellst einen Strichplan für eine begonnene Fineliner-Zeichnung. Die App zeichnet den Plan exakt auf das Foto.

Bild 1: das Foto der Zeichnung. Bild 2: dasselbe Foto; der erlaubte Bereich ist magenta umrandet.

Regeln:
- Nur schwarzer Fineliner. Kein Weiß, keine Farbe, keine deckenden Flächen, kein Radieren.
- Neue Striche nur innerhalb der magenta Umrandung. Bestehende Linien nicht nachzeichnen, nicht überdecken.
- Koordinaten 0..1 relativ zu Bild 1 (0,0 = oben links, x nach rechts, y nach unten). Miss Positionen sorgfältig an Bild 1.
- width als Anteil der längsten Bildkante (Fineliner 0,1–0,5 mm entsprechen meist 0,0005–0,003), darkness 0..1.
- order ist die Zeichenreihenfolge und über strokes und fills hinweg eindeutig.
- Einzelne Linien: strokes. Schraffuren: fills mit polygon (die zu schraffierende Fläche, 3–64 Punkte), angle_deg (0 = waagerecht, 90 = senkrecht, 45 = von links oben nach rechts unten, 135 = von links unten nach rechts oben), spacing (Linienabstand als Anteil der längsten Bildkante, 0,002–0,05; Fineliner-Schraffur meist 0,005–0,012), width, darkness, cross (true = Kreuzschraffur). Die App zeichnet die Schraffurlinien exakt innerhalb des Polygons.

Antworte nur mit dem Strichplan als JSON nach diesem Schema, mit schema_version "2", ohne weiteren Text:
{stroke_plan_schema}
```
